# 五大模型横向对比表

## 一、总览对比

| 维度 | 📏 线性回归 | 🎯 逻辑回归 | ⚔️ SVM | 🧠 神经网络 | 📊 Softmax 回归 |
|------|-----------|-----------|--------|-----------|---------------|
| **预测目标** | 连续数值 | 二分类 + 概率 | 二分类（硬判断） | 任意（回归+分类） | 多分类（K≥3） |
| **输出内容** | 一个实数（如 350 万） | 0~1 的概率（如 0.82） | 类别标签 ± 分数 | 灵活（概率/数值/标签） | K 个概率（和为 1） |
| **决策边界** | 拟合直线/超平面 | 直线/超平面 | 直线 → 核函数后任意形状 | 任意形状 | 直线/超平面 |
| **核心公式** | y = θᵀx | h = sigmoid(θᵀx) | score = b + ΣαⱼyⱼK(x,xⱼ) | 多层非线性变换 | hₖ = softmax(θₖᵀx) |
| **代价函数** | 均方误差（MSE） | 交叉熵（Log Loss） | 铰链损失（Hinge Loss） | 交叉熵 / MSE | 交叉熵（多类） |
| **可解释性** | ⭐⭐⭐⭐⭐ 极高 | ⭐⭐⭐⭐⭐ 极高 | ⭐⭐⭐⭐ 高（支持向量可查） | ⭐⭐ 低（黑盒） | ⭐⭐⭐⭐⭐ 极高 |
| **需要数据量** | 少~中 | 少~中 | 少~中 | 大（万级以上） | 少~中 |
| **训练速度** | 极快 ⚡ | 极快 ⚡ | 中~快 | 慢 🐢 | 极快 ⚡ |
| **特征工程要求** | 需要手动构造 | 需要手动构造 | 核函数自动处理部分 | 几乎不需要 | 需要手动构造 |
| **过拟合风险** | 低 | 低~中 | 中（取决于 C 和 σ） | 高 | 低~中 |
| **输出概率** | — | ✅ 天然输出 | ❌ 不输出 | ✅ 可输出 | ✅ 天然输出 |
| **非线性能力** | ❌ | ❌（除非加多项式） | ✅（核函数） | ✅✅ 最强 | ❌（除非加多项式） |
| **多分类支持** | — | One-vs-All | One-vs-One | ✅ 一个模型搞定 | ✅ 原生支持 |
| **高维小样本** | 容易过拟合 | 加正则化可用 | ✅✅ 最擅长 | 严重过拟合 | 加正则化可用 |

## 二、按"预测目标"分组

### 需要预测连续数值

| 场景描述 | 推荐 | 原因 |
|---------|------|------|
| 关系大致线性，需要解释 | 线性回归 | 系数直接可读，训练瞬间完成 |
| 关系不明确，数据不多 | 线性回归（先试） | 快速 baseline，效果差再升级 |
| 明显非线性，数据量大 | 神经网络（回归模式） | 自动学特征交互，输出层无激活函数 + MSE |

### 需要做二分类（是/否判断）

| 场景描述 | 推荐 | 原因 |
|---------|------|------|
| 需要概率输出（如"患病率 82%"） | 逻辑回归 | sigmoid 天然输出概率，阈值可调 |
| 监管要求可解释（如贷款审批） | 逻辑回归 | 每个特征权重含义明确 |
| 样本少但特征维度高（如基因数据：500 样本 × 20000 基因） | SVM + 线性核 | 正则化天然防过拟合，这是 SVM 成名场景 |
| 不需要概率，数据中等 | SVM + 高斯核 | 边界清晰，泛化能力强 |
| 数据海量（百万级），关系复杂 | 神经网络 | 数据量足够时神经网络表现最优 |

### 需要做多分类（K ≥ 3）

| 场景描述 | 推荐 | 原因 |
|---------|------|------|
| 类别少（3~5），数据不多 | Softmax 回归 | 简单、快、可解释，逻辑回归的多分类版 |
| 类别多但样本少、特征维度高 | SVM（One-vs-One） | 每两类间训练 SVM，适合高维小样本 |
| 类别多且数据海量 | 神经网络 + softmax | 一个模型搞定，不需要训练 K(K−1)/2 个 SVM |

## 三、按"约束条件"选择

### 条件：需要高可解释性

```
线性回归 > 逻辑回归 > SVM >> 神经网络
```

- 线性/逻辑回归：每个 θⱼ 告诉你"xⱼ 每增加 1，y 变多少"或"对几率的影响"
- SVM：可以查看哪些样本是支持向量，比神经网络好一点
- 神经网络：几乎无法解释"为什么会给出这个输出"

### 条件：特征数 >> 样本数（p >> n）

```
SVM（线性核）> 逻辑回归（+ L2）> 线性回归（+ 正则化）>> 神经网络
```

### 条件：数据量极大（百万以上）

```
神经网络 > 逻辑回归/线性回归 >> SVM
```

SVM 的求解复杂度为 O(m²)~O(m³)，百万样本根本跑不动。

### 条件：需要输出概率

```
逻辑回归（二分类）> 神经网络 + sigmoid/softmax > Softmax 回归（多分类）
```

SVM 无法输出概率（除非额外做 Platt Scaling，但不属于标准 SVM）。

## 四、吴恩达的建议（课程原文）

> "当你不知道该用什么的时候，先试 SVM + 高斯核——它在很多场景下表现都不错。"

这个建议的背景是 2000 年代，在深度学习大规模普及之前。现在的实践中：

- **2010 年代以前**：SVM 是"默认首选"
- **现在**：数据少 → SVM；数据多 → 神经网络
- **永远不变的原则**：先用简单模型做 baseline，再考虑是否升级
