# 误差分析（Error Analysis）

> 📚 隶属于 `neural-network-diagnosis` 技能。在步骤 8 中调用。
> 用途：手动检查模型判错的样本，找出错误规律，定向改进。这是**最简单但最有效**的诊断方法。

## 核心理念

> 🏛️ **不要一上来就设计复杂系统。先跑一版简单的，看它错在哪，再定向改进。**
>
> 盲目调参可能浪费时间在不必要的方向上。花 5 分钟看"错题"，效果远好于花 30 分钟瞎调 λ。

## 何时使用

- **所有诊断场景的第一步**（无论是高偏差还是高方差）
- 当你不确定从哪里开始改进时
- 在自动调参（λ 网格搜索等）之前，先了解"错在哪"

## 步骤 1：找出错判样本

```python
# 在验证集上运行前向传播
_, _, _, _, _, H_val = forward_propagation(X_val, Theta1, Theta2)

# 获取预测类别
if is_multiclass:
    y_pred_val = np.argmax(H_val, axis=1).reshape(-1, 1)
else:
    y_pred_val = (H_val >= 0.5).astype(int)

# 找出所有错误
error_mask = (y_pred_val.flatten() != y_val.flatten())
X_errors = X_val_raw[error_mask]        # 错判样本的原始特征
y_true_errors = y_val[error_mask]       # 真实标签
y_pred_errors = y_pred_val[error_mask]  # 预测标签
H_errors = H_val[error_mask]            # 错判样本的概率

n_errors = len(X_errors)
print(f"验证集共 {n_errors} 个错判样本 / {len(y_val)} 总计 ({n_errors/len(y_val):.1%})")
```

## 步骤 2：逐个展示错判样本

```python
# 逐个展示（超过 20 个时分页显示，每页 10 个）
for i in range(n_errors):
    print(f"\n错判样本 {i+1}/{n_errors}:")
    print(f"  特征值: {X_errors[i]}")
    print(f"  真实类别: {y_classes[int(y_true_errors[i])]}")
    print(f"  预测类别: {y_classes[int(y_pred_errors[i])]}")

    # 多分类：展示各类别概率
    if is_multiclass:
        for c in range(K):
            print(f"    P({y_classes[c]}) = {H_errors[i, c]:.1%}")

    # 每 10 个暂停（如果交互模式支持）
    if (i + 1) % 10 == 0 and i + 1 < n_errors:
        input(f"\n--- 已展示 {i+1}/{n_errors}，按 Enter 继续 ---")
```

## 步骤 3：引导用户归类错判原因

展示完所有错判样本后，引导用户分析规律：

> 你能看出这些错判样本有什么共同规律吗？请从以下常见原因中选择：
>
> **A. 特征缺失型** — 样本的某种关键属性没有被纳入特征。例如：
>   - "这些错判的都是玻璃幕墙建筑，但我们没有收集'幕墙类型'这个特征"
>   - "错判样本的窗户朝向都是西晒，但'朝向'不在特征中"
>
> **B. 标签错误型** — 原始标签本身标注有误。例如：
>   - "这个明显是 A 级却被标成了 B 级"
>
> **C. 边界模糊型** — 错判样本都处于类别边界，概率接近。例如：
>   - "这些样本的概率都在 35%-45% 之间（接近 1/K），说明模型自己也分不清"
>
> **D. 缺乏规律型** — 错判样本随机分布，看不出明显模式。
>
> **E. 其他** — 请描述你观察到的规律。

## 步骤 4：根据归类给出改进建议

| 用户归类 | 改进方向 | 具体操作 |
|---------|---------|---------|
| **A. 特征缺失** | 收集新特征 | 在下次训练时把缺失的特征加入 X_raw，重新生成模型 |
| **B. 标签错误** | 清洗数据 | 修正错误标签，重新训练 |
| **C. 边界模糊** | 加大 λ 或收集更多数据 | 边界模糊说明过拟合或数据不够，优先 λ 网格搜索 |
| **D. 缺乏规律** | 可能是高偏差 | 模型本身太简单，增加神经元或层数 |
| **E. 其他** | 根据用户描述定向处理 | 听取用户的领域知识 |

## 改进示例

```
判错的 2 个样本中：
  - 2 个：真实 B 级，预测 A 级
    → 特征：保温厚度 8cm, 窗墙比 0.28（B 级边界样本）
    → 概率：A=52%, B=31%, C=17%（接近 1/3）
    → 结论：处于类别边界模糊地带 (C 类)
    → 建议：λ 网格搜索优先，其次考虑增加数据
```

## 注意事项

1. **错判样本很少时（< 3 个）**：逐个分析很有价值，但统计意义有限
2. **错判样本超过 20 个**：分页展示，每页 10 个，避免信息过载
3. **用户看不懂时**：提供 A-D 选项简化判断，帮用户快速归类
4. **不要代替用户判断**：用户有领域知识（如知道哪些特征可能有用），AI 只负责展示数据和解释含义
5. **如果用户选择跳过**：直接进入自动调参流程（步骤 9），不要强求
