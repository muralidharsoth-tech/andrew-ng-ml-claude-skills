# 神经网络模型效果诊断与提升

## 概述

此技能分**两个阶段**，对已有的神经网络模型进行系统化诊断和优化：

1. **第一阶段：模型效果诊断**（步骤 1-6）—— 数据划分 → 计算误差 → 画学习曲线 → 判断好/坏
2. **第二阶段：模型效果提升**（步骤 7-12）—— 仅在诊断"差"时触发，简单方法优先，最多 3 轮迭代

核心原则：
- **先诊断，再治疗**——不诊断就动手可能越搞越糟
- **仅针对神经网络模型**（通过 `neural-network` 技能生成的 `.py` 文件）
- **简单方法优先**：误差分析 → 调 λ/α → λ 网格搜索 → 改网络结构
- **每次优化后验证**，对比步骤 2 确认的量化标准
- **最多 3 轮优化**，每轮结束后询问用户是否继续
- **新建文件保存优化结果**，原始模型代码一字不改

> 📚 本技能依赖以下参考文件（按需读取，不全部加载）：
> - `references/learning-curve.md` — 学习曲线绘制
> - `references/bias-variance-diagnosis.md` — 偏差/方差诊断决策树
> - `references/lambda-grid-search.md` — λ 网格搜索
> - `references/early-stopping.md` — 早停训练
> - `references/error-analysis.md` — 误差分析
> - `references/kfold-cross-validation.md` — k-fold 交叉验证
> - `references/skewed-class.md` — 偏斜类问题处理

### 步骤 2：确认"效果好"的量化标准

在诊断前，与用户确认判定标准。展示默认值并询问：

> 在开始诊断前，先确认"模型效果好"的判定标准。默认标准如下：
>
> | 指标 | 默认值 | 说明 |
> |------|--------|------|
> | 验证集错误率 | < **{val_error_threshold}** | 主要指标 |
> | 训练/验证差距 | < **{train_val_gap} 个百分点** | 防止过拟合 |
> | 学习曲线 | 趋于平稳（不再明显下降） | 训练充分 |
>
> {如果是偏斜类：偏斜类场景额外要求 F1 分数 > **{f1_threshold}**}
>
> 是否需要调整这些标准？（直接回复"可以"使用默认值，或指定你要修改的阈值，如"验证错误率改为15%"）

**默认阈值（根据分类类型自动选择）：**

| 指标 | 二分类 | 多分类 | 偏斜类 |
|------|:------:|:------:|:------:|
| 验证错误率上限 | < 5% | < 10% | 不适用 |
| 训验差距 | < 3pp | < 5pp | < 5pp |
| F1 分数 | 不适用 | 不适用 | > 0.85 |

> ⚠️ **小数据集提示**：当 m < 30 时，主动告知用户"数据量较小，建议适当放宽标准（如验证错误率放宽 5%~10%）。如果坚持严格标准，优化可能难以达标。"

### 步骤 3：数据划分

> ⚠️ **如果 Step 1 已检测到 `use_existing_split = True`**：
> 直接跳过此步骤，打印："✅ 使用原始模型已有的数据切分（训练集 {m_train} 条 / 验证集 {m_val} 条）"，然后进入 Step 4。

仅在 `use_existing_split = False` 时执行以下逻辑。

根据样本数选择划分策略：

```
m < 50？
  ├── 是 → k-fold 交叉验证（k=5）
  │       读取 references/kfold-cross-validation.md
  │       告知用户：
  │       "数据只有 {m} 条（m < 50），用 60/20/20 切分会导致验证集太小（仅 {val_size} 条），
  │        评估结果波动很大。建议使用 k-fold 交叉验证（k=5），取平均误差。
  │        是否同意？（回复'可以'使用 k-fold，或回复'不'坚持传统切分）"
  │
  └── 否 → 60/20/20 三路切分
           告知用户：
           "数据 {m} 条，使用标准三路切分：
            - 训练集 {train_size} 条 | 验证集 {val_size} 条 | 测试集 {test_size} 条"
```

**注意：** 重新训练时保持原始模型的网络结构（`hidden_size`）、学习率（`alpha`）、迭代次数（`iters`）不变。只修改数据切分和正则化强度 `lam`。

**关键实现细节：**

- 打乱数据前固定随机种子（`np.random.seed(42)`），保证可复现
- k-fold 时设置 `k=5`（m < 20 时降为 `k=3`）
- 切分后打印每组的大小和类别分布

### 步骤 4：计算误差指标

在训练集和验证集上计算：

**分类问题（默认）：**

```python
# 训练误差
_, _, _, _, _, h_train = forward_propagation(X_train, Theta1, Theta2)
y_pred_train = np.argmax(h_train, axis=1).reshape(-1, 1)  # 多分类
J_train = np.mean(y_pred_train != y_train)                 # 错误率

# 验证误差（同理）
J_val = np.mean(y_pred_val != y_val)
```

**偏斜类检测：** 如果任一类占比 < 15%，自动标记为偏斜类，读取 `references/skewed-class.md` 额外计算 Precision、Recall、F1。

输出格式：

```
========== 模型误差报告 ==========
训练集错误率:  0.00%（15/15 正确）  ← ⚠️ 可能有过度训练
验证集错误率: 13.33%（ 2/15 正确）

各类别错误率:
  A级(高效节能): 0.0%（ 5 个样本）
  B级(中等能效): 40.0%（ 5 个样本，2 个判错）
  C级(能效较差): 0.0%（ 5 个样本）
==================================
```

### 步骤 6：输出诊断结论

根据步骤 4-5 的结果，对照 `references/bias-variance-diagnosis.md` 的诊断决策树，输出结论。

**诊断逻辑：**

```
J_train 高（> 阈值）？
  ├── 是 → J_val ≈ J_train（差距 < train_val_gap）？
  │         ├── 是 → 🔴 高偏差（欠拟合）
  │         └── 否 → 🟡 两者都有
  └── 否 → J_val >> J_train（差距 > train_val_gap）？
              ├── 是 → 🔵 高方差（过拟合）
              └── 否 → ✅ 效果良好
```

输出格式：

```
========== 诊断结论 ==========
J_train = 0.00%, J_val = 13.33%
学习曲线特征：J_train 始终很低，J_val 随 m 增大缓慢下降但仍高于 J_train
诊断结果：🔵 **高方差（过拟合）**
  - 模型在训练集上完美（0% 错误），但在验证集上表现差（13% 错误）
  - J_train 和 J_val 之间存在明显 gap（13pp > 目标 5pp）
==============================
```

**如果是"效果良好"**：✅ 诊断完成，不需优化。直接结束。

**如果"存在问题"**：

> 模型存在 **{问题类型}**，建议进入优化阶段。
> 是否开始优化？（直接回复"可以"进入优化，或回复"不了"以当前诊断结果结束）

>
> 推荐策略（简单 → 复杂）：
> ┌─────┬────────────────────┬──────────┐
> │ 优先级 │       方法         │  说明    │
> ├─────┼────────────────────┼──────────┤
> │  ①  │ 误差分析            │ 简单：看错在哪 │
> │  ②  │ 增加迭代次数         │ 简单：可能没训练够 │
> │  ③  │ 减小 λ              │ 简单：释放模型自由度 │

> └─────┴────────────────────┴──────────┘

>

**🔵 高方差路径：**

>
> 推荐策略（简单 → 复杂）：
> ┌─────┬────────────────────┬──────────┐
> │ 优先级 │       方法         │  说明    │
> ├─────┼────────────────────┼──────────┤
> │  ①  │ 误差分析            │ 简单：看错在哪 │

>   真实: B级(中等能效) → 预测: A级(高效节能)
>   各类概率: A=52.3%, B=31.2%, C=16.5%
>
> ...（逐个展示）
>
> 你能看出这些错判样本的共同规律吗？比如：
> - 是否缺少某种特征（如"朝向"、"窗户类型"）？
> - 是否标签本身有问题？
> - 是否都处于类别边界（概率接近）？
>
> 根据你的判断，我会给出定向改进建议。

**根据用户反馈输出改进方向：**

| 用户反馈 | 建议方向 |
|---------|---------|
| 缺少特征信息 | 建议收集新特征（如"幕墙类型"、"朝向"） |

### 步骤 9：简单优化方法

不修改网络结构，仅调整训练参数。按问题类型选择方向：

**高方差 → 增大 λ 或减小 iters：**

> 当前 λ = {old_lam}，建议增大到 {new_lam}（加强正则化）。
> 是否尝试？（回复"可以"执行，或指定你想要的 λ 值）

**高偏差 → 减小 λ 或增加 iters：**

> 当前 λ = {old_lam}，建议减小到 {new_lam}（释放模型自由度）。
> 是否尝试？（回复"可以"执行，或指定你想要的 λ 值）

**执行方式：**
1. 修改原代码中的 `lam` / `alpha` / `iters` 值
2. 重新训练模型
3. 计算新的 J_train / J_val
4. 报告对比结果：

```
简单优化结果（调整 λ）：
  λ: {old} → {new}
  J_train: {old} → {new}
  J_val:   {old} → {new}
  效果: {改善 / 恶化 / 基本不变}
```

先做 λ 网格搜索找最佳 λ，再基于最佳 λ 调整网络结构。

### 步骤 11：效果验证 + 迭代决策

每次优化（步骤 9 或 10）后，执行验证：

1. 重新计算 J_train / J_val
2. 与步骤 2 的标准对比
3. 判断是否达标

**达标情况：**

```

本轮操作：λ 网格搜索 → best λ = 3.0
  J_train: 0.00% → 6.67%

  训验差距: 13.33pp → 0.00pp

  - 训验差距 0.00pp < 目标 5pp ✓
  - 学习曲线趋于平稳 ✓
==========================================
```

**未达标 + 还有轮数（round < 3）：**

```

  J_val = {current}，目标 < {target}
  差距：{gap}

是否继续下一轮优化？
（回复"可以"继续第 {round+1} 轮，或回复"不了"以当前最优结果结束）
```

**未达标 + 已达上限（round = 3）：**

```

  第 2 轮：λ 网格搜索 → best λ = 3.0 → J_val 13.3% → 6.7%

  - 次选方案：尝试收集新特征（如"朝向"、"建筑类型"）
```

**优化后效果变差的情况：**

> ⚠️ 本轮优化导致效果**恶化**：
> J_val: {before} → {after}（变差 {delta}）
>
> 已回滚到本轮优化前的最佳参数。
> 是否换一个方向继续优化？（回复"可以"换方向，或回复"不了"结束）

### 步骤 12：输出优化结果

优化完成（达标/上限/用户终止）后：

1. **新建优化代码文件**：`neural_network_optimized_{YYYYMMDD}_{HHMMSS}.py`

## 关键注意事项

### 编码问题
Windows GBK 环境下，`print` 中的 Unicode 特殊字符需替换：`θ→theta`, `λ→lambda`, `δ→delta`。matplotlib 的 label/title 不受影响。

### 无头环境
诊断代码中必须 `matplotlib.use('Agg')`，用 `plt.close()` 代替 `plt.show()`。

### 小数据集
- m < 50 自动触发 k-fold CV
- m < 20 时 k-fold 的 k 降为 3，并提示用户放宽标准
- m < 10 时诚实告知数据太少，诊断结果仅供参考

### 原始文件保护
- 原始 `.py` 文件**一字不改**
- 优化后生成新文件，文件名带 `_optimized` 标识和新的时间戳
- 每轮优化的最佳参数保存在内存中，支持回滚

### 代码修改策略
- 优先通过正则替换修改参数（`lam = {OLD}` → `lam = {NEW}`）
- 如果启用了早停：替换 `gradient_descent()` 函数定义和调用
- 如果修改了网络结构：同步修改 Theta 初始化、forward/back prop 的维度
- 修改后在文件头追加优化记录注释
