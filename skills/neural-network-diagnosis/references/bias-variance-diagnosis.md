# 偏差/方差诊断（Bias-Variance Diagnosis）

> 📚 隶属于 `neural-network-diagnosis` 技能。在步骤 6（诊断结论）和步骤 7（策略推荐）中调用。
> 用途：根据 J_train / J_val 数值和学习曲线形状，判断模型是欠拟合、过拟合还是两者都有。

## 诊断决策树

```
计算 J_train 和 J_val
        │
        ▼
J_train 高（错误率 > 判高阈值）？
  │
  ├── 是 → J_val ≈ J_train（差距 < train_val_gap）？
  │         ├── 是 → 🔴 高偏差（欠拟合）
  │         │         J_train 高、J_val 高、两者贴在一起
  │         │         模型太简单，学不明白
  │         │
  │         └── 否 → J_val 更高？
  │                   ├── 是 → 🟡 两者都有
  │                   │         模型简单但同时也在过拟合
  │                   └── 否 → ⚠️ 异常（重新检查计算）
  │
  └── 否（J_train 低）→ J_val >> J_train（差距 > train_val_gap）？
              ├── 是 → 🔵 高方差（过拟合）
              │         J_train 低、J_val 高、两者之间有 gap
              │         模型背下了训练集，泛化差
              │
              └── 否 → ✅ 效果良好
                        两者都低且靠拢
```

## 四种典型学习曲线

### 🔴 形状 A：高偏差（欠拟合）

```
Error ↑
      │  ●  ●  ●  ●  ●  ●  ← J_train 一直很高
  0.3 ┤━━━━━━━━━━━━━━━━━━━━
      │  ●  ●  ●  ●  ●  ●  ← J_val 也很高
  0.2 ┤━━━━━━━━━━━━━━━━━━━━
      │
      │  两条线贴在一起，都在高位。
      │  加再多数据线也不会再降了。
      │  模型根本学不明白。
      └─────────────────────→ m
```

| 特征 | J_train | J_val | 两者关系 | 加更多数据？ |
|------|:------:|:-----:|---------|:----------:|
| 高偏差 | 高 | 高 | 贴得很近 | ❌ 没用 |

### 🔵 形状 B：高方差（过拟合）

```
Error ↑
      │  ●J_train 一直很低
  0.0 ┤   ●●●●●●●
      │
      │           ● ← J_val 很高，但随 m 增大在下降
  0.3 ┤         ●
      │       ●
  0.2 ┤     ●
      │   ●
      │   两条线之间有 gap，但 gap 在缩小。
      │   加更多数据有用！
      └────────────────────────→ m
```

| 特征 | J_train | J_val | 两者关系 | 加更多数据？ |
|------|:------:|:-----:|---------|:----------:|
| 高方差 | 很低 | 高 | 有 gap，gap 随 m 增大而缩小 | ✅ 有用 |

### 🟡 形状 C：两者都有

```
Error ↑
      │  ●J_train 高
  0.2 ┤   ●
      │     ●
  0.1 ┤
      │        ●J_val 更高
  0.4 ┤      ●
      │    ●

      │     两条线都不低，且有 gap
      └────────────────────────→ m
```

| 特征 | J_train | J_val | 两者关系 | 加更多数据？ |
|------|:------:|:-----:|---------|:----------:|
| 两者都有 | 高 | 更高 | 有 gap | ⚠️ 有帮助但不充分 |

```
Error ↑
      │  ●J_train 低
  0.0 ┤   ●●●●●●●
      │  ●●●●●●●  ← J_val 也低，靠在一起

      │  两条线低且贴在一起。
      │  模型泛化良好！
      └────────────────────────→ m
```

| 特征 | J_train | J_val | 两者关系 | 加更多数据？ |
|------|:------:|:-----:|---------|:----------:|
| 良好 | 低 | 低 | 贴得很近 | ⚠️ 不需要 |

## 诊断口诀

```
J_train 高？
  ├── 是 → 高偏差（欠拟合）
  └── 否 → J_val ≫ J_train？
            ├── 是 → 高方差（过拟合）
            └── 否 → ✅ 模型不错！微调即可
```

## 对策速查表

### 🔴 高偏差（欠拟合）→ 模型太简单

| 优先级 | 操作 | 具体做法 | 原理 |
|--------|------|---------|------|
| 1 | 误差分析 | 手动检查错判样本 | 可能不是模型问题，是特征缺失 |
| 2 | 增加迭代次数 | `iters` 翻倍或加至训练收敛 | 可能训练不够久 |
| 3 | 减小 λ | 如 λ=1.0 → 0.1 | 释放模型自由度，允许更复杂边界 |
| 4 | 增加隐藏层神经元 | 如 6 → 12（+50%~100%） | 更多参数 = 更强表达能力 |
| 5 | 增加隐藏层层数 | 1 层 → 2 层 | 更深网络，分层提取特征 |

> ❌ **不要做的事：加更多数据。** 模型本身太简单，再多的数据也学不好。

### 🔵 高方差（过拟合）→ 模型在背训练集

| 优先级 | 操作 | 具体做法 | 原理 |
|--------|------|---------|------|
| 1 | 误差分析 | 手动检查错判样本 | 了解过拟合模式 |
| 2 | 增大 λ | 如 λ=0.01 → 1.0 | 加强正则化惩罚 |
| 3 | λ 网格搜索 | 10 个候选值系统搜索 | 找最佳 λ |
| 4 | 早停训练 | 验证误差不降时提前停止 | 在过拟合前踩刹车 |
| 5 | 减少隐藏层神经元 | 如 12 → 6 | 降低模型容量 |
| 6 | 收集更多数据 | 最根本的解法 | 数据多了模型背不下来 |

> ❌ **不要做的事：减小 λ 或增加神经元。** 会让过拟合更严重。

### 🟡 两者都有

先用 λ 网格搜索找到最佳 λ，再根据剩余问题（偏偏差还是偏方差）选择结构调整方向。
